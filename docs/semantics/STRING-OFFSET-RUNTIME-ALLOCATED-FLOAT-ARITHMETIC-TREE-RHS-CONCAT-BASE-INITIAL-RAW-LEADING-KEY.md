The syntax-only raw-FLOAT RHS grammar recurses through ADD, SUBTRACT, MULTIPLY
and DIVIDE as well as its existing unary signs and FLOAT casts. Both operands
must recursively belong to that grammar. Grouping and operand order remain
explicit; the rules do not flatten arithmetic or supply numeric answers.

The existing allocation body remains literal. Proper immediate left/right
SOURCE and the complete right STRING-cast subtree authenticate the exact
typed quiet FLOAT VALUE, captured/live precision and both false CONCAT flags.

one right row at resultID-1 before CONCAT appends its final row. Full prefix
CASTSTRING and CONCAT state equalities retain their existing authority.
The genuine KNOWN temporary owns the string; registry rows add no roots.

constant operations accepted by `zend_try_ct_eval_binary_op`. Emitted numeric
operations retain the existing recursive VALUE certificate and exact quiet
whole-state result. FLOAT casts change only RESULT. Installed folded pools
retain their existing trust boundary; no new source-to-pool theorem is added.

negative zero. The reference original uses emitted arithmetic over FLOAT casts
and folded children to retain -12.5. Their saved offsets still select the minus

quiet result. Previously admitted infinities retain the existing rules.

multirow RHS allocation and wider owners, release and lifetimes remain partial.
