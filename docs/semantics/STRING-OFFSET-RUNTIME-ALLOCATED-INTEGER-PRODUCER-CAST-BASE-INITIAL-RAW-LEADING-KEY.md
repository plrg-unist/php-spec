Allocated STRING casts now accept existing quiet typed-PINT child certificates,
including folded signs and genuinely emitted arithmetic. Parent false CODE,
positive line/no read, equal own/child precision, signed64 result outside0..9,
exact decimal bytes/prefix/cast replay and genuine non-NUL REQUEST KNOWN ownership
remain required. No new arithmetic or conversion algorithm is introduced.

The only producer change removes the bare integer shape filter, binds the result
from VALUE before its unchanged range guard, and authenticates the complete child
SOURCE subtree. Old raw literal children have singleton walks and retain their
parser-literal equality, so their closed evidence needs no replay.

SOURCE and VALUE are separate authority: a folded sign may retain correct VALUE
when an indexed raw descendant is shadowed. The new allocation certificate refuses
that state. It adds no uniform descendant CODE/pool/precision demand; unused raw
leaf pool or precision changes remain admissible when VALUE does not use them.
