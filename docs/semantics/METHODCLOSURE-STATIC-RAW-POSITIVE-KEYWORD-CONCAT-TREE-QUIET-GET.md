Bounded static USER method Get captures accept UnaryPlus of raw TRUE/FALSE/NULL
ConstFetch leaves inside recursive CONCAT class and method selectors. Simple and
fully qualified Name constructors retain their original Boolean/null authority;
quiet integer conversion contributes `1` or `0` through pure integer text.

The rule authenticates the complete operator, its actual PCFIELD0 ConstFetch and
that node's actual Name child, including metadata. Recursive CONCAT checks every
actual child. Exact folded root PSTRING bytes remain mandatory; child pools are
unnecessary. Class normalization occurs once after the full join, while method
names use casefold only. New helper success plus previous-helper refusal keeps
all earlier selector arms unchanged.

The matching engine's `zend_compile_unary_pm` and
`zend_try_ct_eval_unary_pm` fold through multiplication by integer one; the pure
`coerce_number` and `unary_apply` rules consume the original Boolean/null input
and produce the corresponding integer.

owner and cleanup bounds. Bare signs, nested/coercive/FLOAT/CV children, wider
producers/lifetimes and all paused boundaries remain partial.
